# DOM Map — seletores esperados pelo blueprint

Este mapa existe para impedir nova reinterpretação na fase de implementação.

- `#film` — área de scroll que controla a timeline.
- `#stage` — viewport pinado.
- `#camera` — wrapper único responsável por pan/zoom.
- `#office` — composição inicial da empresa.
- `#networkPath` — path SVG principal da rede.
- `#networkFlow` — cópia do path com stroke verde animável.
- `#networkPacket` — pulso que percorre o path.
- `#faultSegment` — trecho da linha que falha.
- `#computer` — estação acompanhada pela câmera.
- `#computerAlert` — indicação visual da falha.
- `#diagnosticPath` — path percorrido pelo diagnóstico.
- `#diagnosticSignal` — sinal visual do suporte.
- `#processCloud` — camada com processos dispersos.
- `.process-fragment` — planilha, WhatsApp, papel, cobranças.
- `#app` — interface nascente.
- `.ui-shell`, `.ui-sidebar`, `.ui-module`, `.ui-metric` — partes da interface montadas em sequência.
- `#controlePlus` — marca/estrutura do produto.
- `#realProductScreen` — screenshot real do Controle+.
- `#capabilities` / `.cap` — Rede, Suporte e Software no pullback final.
- `#brandFinal` — RICHARD.TI.
- `#brandTagline` — “Tecnologia para sua empresa funcionar.”
- `#brandCta` — “Falar com Richard →”.
- `#caption` — única legenda narrativa ativa.
