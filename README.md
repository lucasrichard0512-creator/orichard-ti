# Richard.TI — V8 Cinematic

Versão focada em sensação de vídeo controlado pelo scroll.

Principais mudanças:
- 8 cenas curtas em um palco fixo.
- Troca de cena mais rápida: ~25–30% de viewport por cena no mobile.
- Texto em uma área fixa separada do visual no celular.
- Títulos entram linha a linha, com hold e saída; não há crossfade de textos por cima um do outro.
- Visual contínuo: operação → rede → falha → suporte → processos → sistema → Controle+.
- Controle+ sem texto sobre a screenshot.
- WhatsApp flutuante oculto durante o filme no mobile.
- Tracking e UTMs preservados.

- ga4Id
- metaPixelId
