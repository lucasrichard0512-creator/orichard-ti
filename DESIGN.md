# Richard TI — Direção visual

## Objetivo

Transmitir competência técnica, clareza e profissionalismo sem parecer uma empresa de tecnologia genérica. O site deve converter visitas em conversas no WhatsApp e, ao mesmo tempo, funcionar como demonstração visual da qualidade do trabalho.

## Conceito

**Industrial Tech / Editorial Scrollytelling**

- Fundo quase preto
- Verde-lima como cor de ação e progresso
- Tipografia grande e condensada visualmente
- Grid técnico discreto
- Muito contraste e espaço negativo
- Elementos fixos/sticky que evoluem conforme a rolagem
- Case do Controle+ em fundo claro para criar uma mudança de capítulo

## Paleta

- Background: `#070808`
- Surface: `#101311`
- Border: `#252a25`
- Text: `#f5f6f2`
- Muted: `#9da49d`
- Accent / CTA: `#c7ff42`
- Case background: `#e7ece2`
- Case text: `#0b0e0b`

## Tipografia

- Headlines: Space Grotesk
- Interface / body: Inter

## Regras de conversão

1. O primeiro CTA deve falar sobre o problema do cliente, não sobre “iniciar um projeto”.
2. Serviços são apresentados como problemas operacionais resolvidos.
3. O Controle+ aparece como prova de capacidade, não como produto principal da Richard TI.
4. Tecnologias usadas no projeto são informação secundária.
5. O WhatsApp é o principal ponto de conversão.
6. Não usar métricas, depoimentos ou resultados que não possam ser comprovados.
